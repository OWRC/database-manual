## G.34 Incorporation of Bedrock Elevations as Bedrock Picks

* Tables
    + D_BOREHOLE
    + D_PICK

* Views 
    + V_SYS_AGENCY_ORMGP
    + V_SYS_BH_BEDROCK_ELEV
    + V_SYS_LOC_COORDS
    + V_SYS_PICK_BEDROCK_TOP
    + V_SYS_RANDOM_ID_BULK_001

* Estimated Recurrence Time: As needed

For locations where a bedrock elevation has not been incorporated in the
D_PICK table through direct user interpretation, the value found in D_BOREHOLE
(BH_BEDROCK_ELEV) can be used instead.  Refer to Appendix G.7 for details
concerning how this field is populated.

For inclusion, these lcoations should be checked for being within the ORMGP
study area and having a QA_COORD_CODE that is less than '6' (which relates to
position accuracy).  In addition, V_SYS_BH_BEDROCK_ELEV is called to examine
the GEOL_SUBCLASS_CODE; this is used to tag those geologic layers that should
not be used for populating the D_PICK table.  Usually this relates to likely
invalid values that cannot be (or have not been) checked against their
original data sources.

This is accomplished through

    insert into d_pick
    (
    loc_id
    ,sys_record_id
    ,geol_id
    ,formation
    ,geol_unit_code
    ,gnd_elev
    ,top_elev
    ,sessionnum
    ,data_id
    ,sys_temp1
    ,sys_temp2
    )
    select
    t1.loc_id
    ,t2.sri
    ,t1.geol_id
    ,t1.formation
    ,t1.geol_unit_code
    ,t1.gnd_elev
    ,t1.top_elev
    ,t1.sessionnum
    ,t1.data_id
    ,t1.sys_temp1
    ,t1.sys_temp2
    from 
    (
    select
    d.loc_id
    ,vbed.geol_id
    ,'Top of Bedrock' as formation
    ,7 as geol_unit_code
    ,d.ground_elev as gnd_elev
    ,d.bedrock_elev as top_elev
    ,576 as sessionnum
    ,240500576 as data_id
    ,'20260423a' as sys_temp1
    ,20260423 as sys_temp2
    ,row_number() over (order by d.loc_id) as rkey
    from 
    v_gen_borehole as d
    inner join v_sys_agency_ormgp as vorm
    on d.loc_id=vorm.loc_id
    inner join v_sys_loc_coords as vcoord
    on d.loc_id=vcoord.loc_id
    inner join v_sys_bh_bedrock_elev as vbed
    on d.loc_id=vbed.loc_id
    where
    vcoord.qa_coord_code< 6
    and d.bedrock_elev is not null
    and d.ground_elev is not null
    and ( vbed.rec_status_code is null or (vbed.rec_status_code < 100 and vbed.rec_status_code <> 15) )
    and d.loc_id not in
    ( select loc_id from d_pick where geol_unit_code= 7 )
    and d.loc_id <> -2147483443
    ) as t1
    inner join
    (
    select
    t.sri
    ,row_number() over (order by t.sri) as rkey
    from 
    (
    select
    top 5000
    v.new_id as sri
    from 
    v_sys_random_id_bulk_001 as v
    where 
    v.new_id not in
    ( select sys_record_id from d_pick )
    ) as t
    ) as t2
    on t1.rkey=t2.rkey

Note that the SYS_TEMP1, SYS_TEMP2, DATA_ID and SESSIONNUM field values should be
modified to reflect the current date and a new import (escpecially with regard
for the latter).  In addition, the 'select ...' portion of the SQL statement
should be run to determine the number of records to be added.  This number
should be reflected in the 'top ...' part of the statement for generating
random identifiers.  

As a test, a set of 'Top of Precambrian' was added to the D_PICK table.  This
was initially to be used as a check for invalid location coordinates.  The
following code was used in this case.

    select
    loc_id
    ,t2.sri as sys_record_id
    ,geol_id
    ,gnd_elev
    ,top_elev
    ,geol_unit_code
    ,formation
    ,sessionnum
    ,data_id
    ,sys_temp1
    ,sys_temp2
    into temphold.dbo.test_pick_prec_20261118a
    from 
    (
    select
    d2.loc_id
    ,d2.geol_id
    ,v.z as gnd_elev
    ,d2.geol_top_elev as top_elev
    ,55 as geol_unit_code
    ,'Top of Precambrian' as formation
    ,579 as sessionnum
    ,240500579 as data_id
    ,'20261118bb' as sys_temp1
    ,20261118 as sys_temp2
    ,row_number() over (order by d2.loc_id) as rkey
    from 
    (
    select
    d.loc_id
    ,min( d.geol_id ) as geol_id
    from 
    d_geology_layer as d
    inner join 
    (
    select
    loc_id
    ,geol_top_elev
    from 
    d_geology_layer
    where
    geol_mat1_code= 21
    and geol_top_elev is not null
    group by
    loc_id,geol_top_elev
    ) as t
    on d.loc_id=t.loc_id and d.geol_top_elev=t.geol_top_elev
    group by
    d.loc_id
    ) as t2
    inner join d_geology_layer as d2
    on t2.geol_id=d2.geol_id
    inner join v_sys_loc_coords as v
    on d2.loc_id=v.loc_id
    left outer join 
    (
    select
    loc_id as lid_dp
    from
    d_pick
    where
    geol_unit_code= 55 
    ) as dp
    on d2.loc_id=dp.lid_dp
    where
    dp.lid_dp is null
    and v.qa_coord_code < 6
    and ( d2.rec_status_code is null or ( d2.rec_status_code < 100 and d2.rec_status_code <> 15 ) )
    ) as d3
    inner join 
    (
    select
    t.sri
    ,row_number() over (order by t.sri) as rkey
    from 
    (
    select
    top 100000
    new_id as sri
    from 
    v_sys_random_id_001
    where
    new_id not in 
    ( select sys_record_id from d_pick ) 
    ) as t
    ) as t2
    on d3.rkey=t2.rkey

The temporary table was then inserted into the picks table.
